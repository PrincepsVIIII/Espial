# Espial Web

This directory will contain the standalone SvelteKit/TypeScript application. It is
a presentation and browser-session client for Espial Core, not a second domain
backend.

Phase 1 scaffolding, design tokens, routes, typed API client, authentication states,
overview, resource table, and live connection behavior are specified in the
[implementation plan](../docs/plans/PHASE_1_IMPLEMENTATION.md). UI direction lives
in the [frontend plan](../docs/FRONTEND_UI_PLAN.md).
